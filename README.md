# مؤشر البورصة المصرية

تطبيق ويب لمتابعة أسهم البورصة المصرية: الأسعار، المؤشرات الفنية، وحالة الجلسة.
يُثبَّت على الشاشة الرئيسية ويعمل كتطبيق مستقل.

## المميزات

- حالة السوق لحظياً (مفتوح / لم يفتح / أُغلق / إجازة) مع العد التنازلي
- قائمة متابعة بالأسعار ونسب التغير ورسم مصغّر لآخر ثلاثين جلسة
- تفاصيل كل سهم: رسم بياني لمئة وعشرين جلسة مع متوسطي عشرين وخمسين
- مؤشرات: مؤشر القوة النسبية، المتوسطات المتحركة، الدعم والمقاومة، السيولة
- تنبيهات داخل التطبيق عند اختراق مقاومة أو كسر دعم أو تشبع
- يعمل بدون اتصال (آخر نسخة محفوظة)

## مصدر البيانات

وسيط على كلاودفلير يجمع بين تاريخ الأسعار من ياهو فاينانس وسعر الجلسة من مباشر
بتأخير خمس عشرة دقيقة. عنوانه مضبوط داخل `index.html` في المتغير `WORKER`.

## التشغيل محلياً

```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`

> خدمة العمل والتثبيت يحتاجان اتصالاً آمناً، وهو متوفر تلقائياً على صفحات جيت هب.

## تعديل قائمة الأسهم

في `index.html` عدّل المصفوفة `DEFAULT` وأضف الأسماء العربية في `NAMES`.

---

تحليل آلي لأغراض المعلومات وليس نصيحة استثمارية.
